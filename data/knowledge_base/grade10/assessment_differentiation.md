# Grade 10 English — Assessment and Differentiation

## Purpose
This guidance supports mixed-ability English grammar classes by providing support tasks for learners who need scaffolding and advanced extension tasks for confident learners.

Use diagnostic questions before teaching and formative checks during tasks. Offer scaffolded and extension versions without changing the core learning objective. Rubrics should use observable criteria and answer keys should explain acceptable alternatives.

## Suggested lesson evidence
A classroom-ready plan should state measurable objectives, show realistic timing, include learner participation, and provide an answer key or assessment criteria.
